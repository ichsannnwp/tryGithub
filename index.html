Alur Belajar Git Panduan Live Share Lihat Kontributor

Misi Praktek: 5 Langkah Menjadi Git Explorer

Centang setiap langkah setelah kamu berhasil menyelesaikannya

0/5 Selesai (0%)

1. Clone Repository ke Komputermu

Langkah 1

Buka terminal di komputermu, arahkan ke folder yang kamu inginkan, lalu jalankan perintah clone:

git clone <URL_REPOSITORY_INI>

2. Buka Folder & Buat Branch Baru

Langkah 2

Masuk ke dalam folder project lalu buat branch kerja dengan namamu:

git checkout -b fitur-kontribusi-nama-kamu

3. Modifikasi File contributors.json

Langkah 3

Buka file contributors.json di teks editor kamu, tambahkan datamu ke dalam array JSON:

{
  "name": "Nama Lengkap Kamu",
  "role": "Git Explorer / Siswa",
  "github": "username_github_kamu",
  "badge": "Contributor",
  "quote": "Praktek git cloning berjalan sukses!"
}

4. Commit Perubahanmu

Langkah 4

Simpan perubahan ke riwayat Git:

git add . && git commit -m "feat: tambah profil kontributor baru"

5. Push ke GitHub & Buat Pull Request

Langkah 5

Kirim perubahan branch ke GitHub lalu buka Pull Request agar kode digabungkan:

git push origin fitur-kontribusi-nama-kamu

Cara Menjalankan Live Share & Buka di Browser

Bagikan sesi coding secara real-time ke teman atau audiens

1

Jalankan Web Server Lokal

Di terminal proyek ini, jalankan server bawaan Python:

python3 -m http.server 3000

Lalu buka http://localhost:3000

2

Buka Sesi Live Share

Instal extension Live Share di VS Code. Klik ikon Live Share di sidebar kiri atau status bar bawah, lalu pilih Share.

Link kolaborasi akan otomatis disalin ke clipboard untuk kamu bagikan ke teman.
3

Share Port (Buka di Browser Teman)

Agar temanmu bisa membuka web ini di browser mereka tanpa perlu instal server:

  • Buka tab Live Share di VS Code
  • Klik menu Share Server...
  • Masukkan port 3000

🎉 Temanmu bisa langsung buka http://localhost:3000 di browser mereka!
